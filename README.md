## 📖 About This Repository

This repository contains my personal notes and practice code as I master the Python programming language. It serves as both a hands-on workspace for coding experiments and a complete reference cheatsheet for future use.

## 📂 Repository Structure

The repository is organized by topic. Each folder contains Python (`.py`) scripts dedicated to practicing and testing specific concepts.

*   **Basics & Data Types:** Introduction, Variables, Type Casting, Strings, Numbers, and Booleans.
*   **Operators:** Arithmetic, Assignment, Comparison, Logical, Identity, and Membership operators.
*   **Data Structures:**
    *   `Lists/`
    *   `Tuples/`
    *   `Sets/`
    *   `Dictionaries/`
*   **Control Flow:**
    *   `Conditional Statements/` (if, elif, else, match)
    *   `Loop/` (for, while, range)
*   **Functions & Modules:**
    *   `Functions/` (Arguments, Lambda, Scope, Recursion, Decorators)
    *   `Modules/` (Importing, Built-in modules)
*   **Advanced Topics:**
    *   `Datetime/`
    *   `Range/`
    *   Regular Expressions (RegEx)
    *   JSON Parsing & Formatting
    *   PIP Package Manager
    *   Error Handling (Try / Except)
